## 🚀 How to Run

1. Install Python 3 on your computer.
2. Clone this repository:

   ```bash
   git clone https://github.com/atharv25-hirde/python-code-collection
   ```

3. Navigate to the repository folder.
4. Run any Python program:

   ```bash
   python filename.py
   ```
